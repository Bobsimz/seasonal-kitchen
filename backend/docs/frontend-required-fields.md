## DTO Enrichment Principles

- Keep numeric values numeric; frontend can format currency and large counts.
- For business labels such as buying signal, trend direction, notification category, and alert severity, backend should return stable enum/string fields.
- For purely presentational icons/colors, frontend can map from semantic fields unless demo parity requires examples.
- All list APIs should continue using the common `ListResponse<T>` shape.
